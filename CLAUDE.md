# Portfolio Agent instructions

Read `AGENTS.md`, `docs/AI_HANDOFF.md`, `docs/CODEX_HANDOFF.md` and
`docs/CODEX_RECOVERY.md` before changing this project. These instructions apply
to Claude Code as well as other maintainers. New owner decisions and current
code supersede old historical sections. Preserve the existing production bot,
read-only source workbook, private state and all access/valuation safeguards.
Credentials must be supplied through secure settings, never committed or printed.

Every new feature or user-visible behavior change must update `README.md`,
`docs/FEATURES.md` and the relevant topic/runbook in the same pull request. Include
permissions, dependencies, failure and privacy behavior, workflows and validation;
never put credentials or private financial/user data in public documentation.
